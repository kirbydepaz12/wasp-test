WASP Mobile Bridge

Staging compatibility endpoint for Subsonic and OpenSubsonic music apps. WASP remains the music server; this layer only translates client requests.

Server URL for compatible apps:

  • Sign into your WASP member account in the web player.
  • Open Account Settings → Mobile and generate a device credential (the administrator must first enable Mobile Bridge).
  • Enter this server URL, your WASP username, and the generated app password in your music player. OpenSubsonic apps supporting API keys can instead use the generated key directly.
  • Music from v15 and publicly reachable downstream WASP peers appears after the administrator enables Mobile Bridge and synchronizes the v15 gateway under Admin → Network → Connected Peers.
Staging release v16.0.5: native WASP with Subsonic compatibility. Source peer audio is streamed on demand, not imported. Never enter your regular website password into a third-party mobile player.
